# Fonts

`Geist-Variable.woff2` and `GeistMono-Variable.woff2` are Geist and Geist
Mono by Vercel, copied unchanged from the npm package `geist` 1.9.2
(`dist/fonts/geist-sans/` and `dist/fonts/geist-mono/`). They are used by the
Brand theme (`src/index.css`).
